## Musanze Harvest Intelligence Service

**GitHub username:** cxnisme

> **The dataset is synthetic.** It is generated by `data/generate_data.py` from the seed 7889; no real farm was measured. This is a classroom prototype, not a replacement for an agronomist, and must not be used to decide access to finance, insurance or public services.

## Problem
A potato cooperative in Musanze needs (1) a harvest estimate in tons per farm, (2) a flag for farms at high production risk (yield per hectare below the median), and (3) groups of farms with similar conditions. Training and command-line prediction run locally without internet; a FastAPI service exposes the same predictions for a future mobile app.

## Environment
- Python **3.12.3** (3.10+ should work)
- Tested on: **Windows 11 (build 26200), Python 3.12.3**

## Setup and run
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python run_all.py --student-id ug25/27889@ines.ac.rw --seed 7889
python predict.py --json samples/valid.json
python predict.py --json samples/invalid.json     # deliberately invalid -> clear error, exit code 2
pytest -q
uvicorn app:app --host 127.0.0.1 --port 8000      # interactive docs: http://127.0.0.1:8000/docs
```
`run_all.py` rejects any seed other than 7889. It recreates the CSV (260 rows = 257 base + 3 duplicates), writes the SHA-256 fingerprint, validates and cleans, trains regression/classification/clustering, saves models, artifacts, plots and the PDF report. `python data/generate_data.py` alone recreates only the CSV.

## API examples
```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/model-info
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d @samples/valid.json
```
Valid response (fields): `verification_code`, `yield_estimate_tons`, `high_risk_prediction`, `high_risk_label`, `high_risk_probability`, `cluster`, `cluster_profile`, `notice`.
Invalid input returns HTTP 422 with `{"error": "invalid_input", "details": [{"field", "problem", "type"}]}`; missing models return 503.

## Results (held-out test set, 65 farms; see `artifacts/`)
- Regression: linear regression selected by 5-fold CV RMSE — MAE 0.9468 t, RMSE 1.1752 t, R² 0.8151 (mean baseline R² −0.0222).
- Classification: logistic regression selected by 5-fold CV ROC-AUC — precision 0.8649, recall 1.0000, F1 0.9275, ROC-AUC 0.9811.
- Clustering: K = 2 chosen by silhouette (0.2403, a weak structure).

## Known limitations
- Synthetic data from a simple linear rule plus Gaussian noise; scores will not carry over to real farms.
- Small test set (65 rows), so metrics are uncertain. Clusters are weakly separated.
- Inputs outside the training ranges are rejected rather than extrapolated.
- Human review is required for every output.
